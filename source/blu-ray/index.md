# Blu-rayオーサリング

Blu-rayオーサリングとは、Blu-rayディスクのファイル形式に基づいて動画、音声ファイルを加工することです。ここでは次の作業を行います。

* blu-rayのチャプター設定を行う
* 結合したmkvファイルを読み込んで blu-ray ISOフォーマットへエクスポートする

いずれも、 tsmuxer を使って行います。

```{admonition} なぜMKV形式からBlu-rayフォーマットを作成するのか

Blu-rayのオーサリングツール tsmuxerには、複数のMP4, AC-3, M2TSファイルなどを結合して一本のBDMVイメージを作成する機能を備えています。

まず、kdenliveからレンダリングしたMP4を直接結合してM2TSやBlu-rayフォーマットであるBDMV形式への変換を行うと、最初のMP4ファイルだけで終了してしまい結合に失敗します。これは、MP4形式にはストリーミングデータの時間情報（PTS：Presentation Time Stamp）が含まれていないため仕様上の制限となります。いちどすべてのMP4をM2TS形式へ変換する必要があります。

では、MP4を個々のM2TS形式のファイルへ変換してから結合した場合どうなるでしょうか。この場合、チャプターが正常に機能しなくなる不具合が生じます。M2TSへ変換された個々のファイルのPTSはすべて `00:00:00.000` からスタートした時刻で記録されます。このPTS情報のまま結合すると連続した時間軸上のPTSとはならず、チャプター設定した時刻からの頭出しに失敗します。

よって、（PTS情報を持つ）TS形式ではない動画・音声コンテナ形式であらかじめ結合して1本化しておき、ここからtsmuxerによりチャプター情報と共にBDMVイメージを作成する必要があります。この際、元の動画や音声ファイルの解像度やビットレートなど劣化させないことが重要です。劣化せず結合するのに最も適したフォーマットがMKVとなります。
```
